# DECISIONES V79

## Función de nivel (apartado 3; agente de las medallas)
- Archivo: `src/lib/nivelDelLogro.ts`.
- `nivelDelLogro(logro: string, total: number | string | null | undefined): number` → el nivel (1, 2, 3…) que le toca a un logro que cuenta con `total` ya ganados (0 si aún no llega al primer paso o si el logro no cuenta por niveles). `nivelDelLogro('paises', 4)` = 2 (Trotamundos).
- `gradoDeLaMedalla(logro, total): number` → el grado de la medalla que se DIBUJA (siempre ≥ 1; `conocedor` usa los grados 5 y 10).
- `llevaNiveles(logro): boolean` y `PASOS_DE_LOGRO` (los `escalones[].n` de `data/logros/viajero.json`).
- `ChapaDibujo` (`<Chapa logro escalon={TOTAL}>`) ya la usa: pasarle como `escalon` el TOTAL del logro en ese momento (no el orden dentro del día). Para el resumen del viaje, el total sale de `ganado[].n` (el servidor lo manda ahora en `/api/logros/resumen` para país, destino nuevo, maravilla y patrimonio).
