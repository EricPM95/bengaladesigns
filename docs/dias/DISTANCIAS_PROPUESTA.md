# Distancias: propuesta para el documento (Tanda 4)

Modo nuevo: cuando el hueco entre dos paradas no da para lo que se anda más el margen, **primero se acorta el colchón de antes** (sin bajar de 30 min; si ya tiene menos, no se toca) y lo que va entre el colchón y ese tramo se adelanta lo mismo; **solo si no basta se corre lo de después**. La cena va siempre a en punto o a y media (hacia arriba). El documento no se ha tocado: cada línea es la fila como está ahora en `DIAS_ESCRITOS_ROMA.md` → la fila nueva, por tabla. Si la pasas al documento, las tablas quedan iguales a lo que saca el motor.
